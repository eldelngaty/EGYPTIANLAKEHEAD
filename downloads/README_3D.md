# Playable modeled 3D edition

This edition starts in the existing freely walkable 3D campus, with third-person guardian, collision geometry and an orbit camera. The photographic 360 mode is optional only (`SPHINX_TOUR=1`). The campus is an original reference-inspired model, not a surveyed reconstruction of Lakehead.

[Godot project download](https://github.com/eldelngaty/EGYPTIANLAKEHEAD/raw/repair/360-adventure-ux/downloads/Sphinx_Reversal_3D_Project.zip)

Enter closes the guide. WASD walk, Shift run, hold right mouse and drag to orbit, C zoom, R reverse, E interact, M discovered map. Collect three scarabs in Ancient Echo; altar order 3,2,1; key opens chamber; discover map and rescue Nefertiti.

Godot 4.7.2: existing 15/15 quest regression checks passed; graphical public-input movement/orbit checks passed and screenshot captured. Regression quest checks reposition the player; this is not a full human playthrough. Native Windows execution has not been tested on this Linux runner. The Windows package is unsigned.
