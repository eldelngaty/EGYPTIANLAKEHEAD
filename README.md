# Sphinx Reversal — Lakehead Campus Edition

[Download the complete project ZIP](https://github.com/eldelngaty/EGYPTIANLAKEHEAD/raw/refs/heads/main/downloads/Sphinx_Reversal_Campus_Edition.zip)

Open `GAME_GODOT_V5_RUNNING_BASE/project.godot` in Godot and press F5.

Includes the continued game project, all assets, actual game screenshots, gameplay tests, and a packaged PCK. Tested on Godot 4.6.3: headless import and 15 gameplay checks pass for both source and PCK. Windows export templates were unavailable, so no Windows executable is included. Campus architecture is approximate; supplied online references were inaccessible during this pass.

See `RELEASE_NOTES.txt` for validation and known limitations.
